# 결과

같은 holdout 100건을 같은 심판(Claude Sonnet)으로 세 번 채점했습니다. 라운드마다 달라진 것은 상담사에게 넣은 사례 기반 수정 구성입니다.

## 라운드별 검증과 변경

| 라운드 | 주입한 것 | 검증 결과 | 바꾼 것 |
|---|---|---|---|
| r001 | 없음 (기준선) | 합격률 58%, 해결 36건, 이관 17건입니다. dev 실패에서 후보 13개를 만들었습니다. | 수정 6개(범용 5, 주제 1)와 합성사례 2개를 채택했습니다. |
| r002 | r001 채택분 8개. 상담 턴 100%에 들어갔습니다. | 합격률 52%, 해결 13건, 이관 77건입니다. 첫 답변 연결 제안이 68건이었습니다. 기존 기준(종합점수 -0.10)으로는 롤백되지 않았습니다. | 롤백 기준을 5개로 늘렸습니다. 기준 4개에 걸려 8개를 롤백했습니다. 주제별 수정은 주제가 맞을 때만 넣도록 바꿨습니다. |
| r003 | r002 채택분 5개(주제별 수정 4, 합성사례 1). 상담 턴 25%에 들어갔습니다. | 합격률 57%, 해결 29건, 이관 27건입니다. 롤백 기준에 걸리지 않았습니다. | 다음 라운드용으로 수정 5개와 합성사례 1개를 채택했습니다. |

r002 롤백 근거: 합격률 -6%p · 문제해결 -0.31 · 부적절이관 태그 대화당 +0.4 · 이관 비율 +60%p

## 주제별 수정 효과 (r003)

수정이 한 번이라도 들어간 holdout 시나리오를 r001 채점과 비교했습니다.

| 수정 | 주제 | 적용 시나리오 | 점수 변화 평균 | 개선 / 동일 / 악화 | 합격 (r001 → r003) |
|---|---|---:|---:|---:|---:|
| L0007 | 이자/연체금액 | 7건 | +0.23 | 4 / 1 / 2 | 3 → 1 |
| L0008 | 거래내역/잔액조회 | 12건 | +0.40 | 7 / 3 / 2 | 5 → 9 |
| L0009 | 자동이체조회 | 12건 | -0.05 | 3 / 4 / 5 | 10 → 9 |
| L0010 | 환전문의 | 5건 | -0.40 | 0 / 1 / 4 | 3 → 3 |

- 수정이 들어간 시나리오 32건은 평균 +0.125점, 들어가지 않은 68건은 -0.032점이었습니다.
- 차이는 +0.157점이고 95% 구간은 -0.09 ~ +0.41입니다.
- 수정이 없는 시나리오도 다시 실행하면 평균 0.49점 움직였습니다.

## 수정이 답변을 바꾼 방식

- r002의 범용 수정은 "담당 부서 연결을 제안하라"는 문구를 담고 있었습니다. 1턴에 바로 이관한 대화가 14건이었고, 이 중 r001에서 해결된 6건이 모두 이관으로 끝났습니다.
- r003의 L0008은 "앱이 어렵다면 한 단계씩 설명하라"는 수정입니다. 잔액 확인 시나리오에서 r001은 직접 조회가 어렵다는 안내를 반복해 미해결로 끝났습니다. r003은 앱 메뉴를 순서대로 안내해 해결로 끝났습니다(3.0 → 4.2점).

## 의미와 개선 방향

### 확인한 것

- 실패 수집, 수정 생성, 적용, 측정, 롤백을 사람 개입 없이 돌렸습니다.
- 수정 문구는 답변을 실제로 바꿨습니다. r002 첫 답변 연결 제안이 0건에서 68건이 됐습니다.
- 해로운 수정을 지표로 찾아 롤백했습니다. 다음 라운드 이관이 77건에서 27건으로 줄었습니다.

### 효과가 작았던 이유

- 상담 상대인 고객과 채점하는 심판이 모두 AI입니다.
- 같은 시나리오를 다시 실행해도 점수가 평균 0.49점 움직였습니다. 수정 효과 +0.157점은 이 변동 안에 있었습니다.
- 고객 시뮬레이터가 지시문·평가문을 발화로 내보낸 경우가 라운드마다 2 → 4 → 10건으로 늘었습니다.

### 개선 방향

| 방향 | 내용 |
|---|---|
| 측정 안정화 | 시나리오를 여러 번 실행해 평균으로 비교합니다. 고객 발화의 지시문 노출을 걸러 냅니다. 다른 심판 모델로 교차 채점합니다. |
| 수정 단위 검증 | 수정 항목을 하나씩 켜고 끈 비교로 효과를 잽니다. 해로운 수정만 골라 롤백합니다. |
| 사람 피드백 연결 | 앱 상담 기록에 상담 평가를 붙여 수정 후보로 씁니다. 실제 상담 로그로 같은 루프를 돌립니다. |
| 응답 규칙 조정 | '구체 수치 단정 금지' 규칙이 근거의 일반 규정까지 막았습니다. 근거에 있는 일반 규정은 안내하도록 범위를 다시 정합니다. |

실패 사례로 지침을 고치고, 적용하고, 지표로 채택과 롤백을 정하는 구조는 동작합니다. 측정 변동을 줄이고 사람 평가를 연결하면 이 구조로 상담 품질 개선을 자동화할 수 있습니다.
